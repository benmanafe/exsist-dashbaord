# ExSISt Dashboard

Interactive dashboard prototype for ExSISt, built with React, TypeScript, and Vite.

## Requirements

- Node.js 20 or newer
- npm

## Local development

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Available commands

- `npm run dev` starts the development server.
- `npm run build` creates a production build in `dist/`.
- `npm run preview` serves the production build locally.
- `npm run format` formats the source with Oxfmt.

## Project structure

- `src/` contains the React application and styles.
- `public/` contains public logos and static assets.
- `appendix/` contains design-reference assets.
- `.figma/make/site.json` contains the Figma Make site configuration used by the Vite setup.

Dashboard data is currently mocked in the frontend for UI prototyping.
